<small>A collection of some projects I built (my favorites)</small>
* <small>[**Avnac Studio**](https://avnac.design/studio) — Lightweight desktop design tool. 1,000+ downloads. (Canva Alternative)</small>
* <small>[**Clipcat**](https://getclipcat.com/) — Cross-platform clipboard manager with paper-like design. Featured on [**Awesome Wails**](https://github.com/wailsapp/awesome-wails).</small>
* <small>[**Ya-GUI**](https://github.com/d3uceY/Ya-GUI) — GUI for the Ya CLI command alias tool. Featured on [**Awesome Wails**](https://github.com/wailsapp/awesome-wails).</small>
* <small>[**Ya-CLI**](https://github.com/d3uceY/Ya-CLI) — Command shortcut and alias manager.</small>
* <small>[**Cokpyt**](https://github.com/d3uceY/Cokpyt) — The GUI you always wished `pip` shipped with. (pip GUI wrapper)</small>
* <small>[**OpenSus**](https://github.com/d3uceY/OpenSus) — Paste any GitHub URL to view repository activity in one place.</small>
* <small>[**Vectile**](https://github.com/d3uceY/vectile#vectile-your-private-library) — Private, fully local knowledge library with hybrid semantic and full-text search. Everything stays on your machine.</small>
* <small>[**Retna**](https://github.com/d3uceY/Retna) — Reads a color in almost any notation, normalizes it to sRGB, then prints it in another color space or measures it against another color. Contrast from WCAG 2.x by default.</small>
* <small>[**Aka-nasu**](https://github.com/d3uceY/aka-nasu) — Aka Nasu (赤茄子) is a pomodoro focus timer for the desktop. Aka nasu is the Japanese word for red eggplant, another name for a tomato, and the tagline トマトの時計 translates to "the tomato clock."</small>
* <small>[**Water Pump Regulator IoT**](https://github.com/d3uceY/WATER_PUMP_REGULATOR-IOT-) (chill, it's ongoing) — ESP32-based smart water pump controller with automatic tank level monitoring, relay control, and MQTT connectivity for remote monitoring and automation.</small>
